# Neovim Config

Personal Neovim setup built on `lazy.nvim`.

## Highlights

- `fzf-lua` for files, grep, buffers, help, and config search.
- `nvim-lspconfig`, `mason.nvim`, and `blink.cmp` for LSP and completion.
- `conform.nvim` and `nvim-lint` for formatting and linting.
- `snacks.nvim` for explorer, notifications, toggles, quickfile, and zen mode.
- `gitsigns.nvim` and `lazygit.nvim` for Git workflow.
- Rust support via `rustaceanvim`.

## Useful Keys

- `<leader>ff` find files
- `<leader>fg` live grep
- `<leader>fc` find config files
- `<leader>e` explorer at current file
- `<leader>E` explorer at project root
- `<leader>f` format buffer
- `<leader>ca` code action
- `<leader>cr` rename symbol
- `<leader>gg` LazyGit
- `]h` / `[h` next/previous Git hunk
- `<leader>gp` preview Git hunk
- `<leader>xl` diagnostics to location list
